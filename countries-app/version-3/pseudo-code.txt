📊 USERS
-------------------------------------

🔹 GET /get-newest-user  
Description: Retrieves the most recently added user. 
Your SQL command: 

SELECT *
FROM users
ORDER BY user_id DESC
LIMIT 1;

*Dynamic Values:
None
____________________________


🔹 GET /get-all-users  
Description: Retrieves all users from the database.  
Your SQL command:

SELECT * FROM users;

*Dynamic Values:
None
____________________________


🔹 POST /add-one-user  
Description: Adds a new user to the database.  
Your SQL command:

INSERT INTO users (name, country_name, email, bio)
VALUES
  ($1, $2, $3, $4);

*Dynamic Values:
$1 = name
$2 = country_name
$3 = email
$4 = bio

-------------------------------------
📊 SAVED COUNTRIES
-------------------------------------

🔹 GET /get-all-saved-countries  
Description: Retrieves a list of all saved countries.  
Your SQL command:

SELECT country_name
FROM saved_countries;

*Dynamic Values:
None

____________________________



🔹 POST /save-one-country  
Description: Saves a country if it hasn’t already been saved.  
Your SQL command:

INSERT INTO saved_countries (country_name)
VALUES
  ($1)
ON CONFLICT (country_name)
DO NOTHING;

*Dynamic Values:
$1 = country_name


____________________________



🔹 POST /unsave-one-country  
Description: Unsaves a country if it has been saved.  
Your SQL command:

DELETE FROM saved_countries
WHERE country_name = $1;

*Dynamic Values:
$1 = country_name

____________________________



-------------------------------------
📊 COUNTRY COUNTS
-------------------------------------

🔹 POST /update-one-country-count  
Description: Updates (or initializes) the view count for a country.  
Your SQL command:

INSERT INTO country_counts (country_name, count)
VALUES
  ($1, 1)
ON CONFLICT (country_name)
DO UPDATE
  SET count = country_counts.count + 1
RETURNING count;

*Dynamic Values:
$1 = country_name
